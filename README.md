# উত্তরাধিকার ক্যালকুলেটর 🕌

একটি আধুনিক ওয়েব অ্যাপ্লিকেশন যা ইসলামী উত্তরাধিকার আইন (ফারায়েজ) অনুযায়ী সম্পদ বন্টন হিসাব করে। হানাফি মাযহাবের মূলনীতি অনুসরণ করে তৈরি।

## ✨ বৈশিষ্ট্যসমূহ

### 🧮 ক্যালকুলেটর ফিচার
- 🎯 **নির্ভুল হিসাব**: জাবিল ফুরুজ, আসাবা, আউল ও রাদ্দ লজিক সহ
- 👥 **২২+ ওয়ারিশ সাপোর্ট**: পিতামাতা থেকে দূরবর্তী আত্মীয় পর্যন্ত
- 💰 **বহুমুখী সম্পদ**: টাকা, জমি, স্বর্ণ ও রুপার আলাদা হিসাব
- 📊 **ভিজুয়াল চার্ট**: Pie chart-এ বন্টন দেখুন (Recharts)
- 📄 **PDF ডাউনলোড**: বন্টননামা PDF ফরম্যাটে সেভ করুন
- 🖨️ **প্রিন্ট সুবিধা**: সরাসরি প্রিন্ট করার অপশন
- ✅ **ইনপুট ভ্যালিডেশন**: ভুল ইনপুট প্রতিরোধ

### 📚 শিক্ষামূলক কন্টেন্ট
- 📖 **কুরআনিক রেফারেন্স**: ৪টি মূল আয়াত (সূরা নিসা: ৭, ১১, ১২, ১৭৬) তাফসীর সহ
- 📜 **হাদিস সংকলন**: ১০টি সহিহ হাদিস (বুখারী, মুসলিম, তিরমিযী)
- 🎯 **বিশেষ মাসআলা**: মাফকুদ, হামল, খুনসা - বিস্তারিত ব্যাখ্যা সহ
- ❓ **FAQ**: ৪০+ প্রশ্নোত্তর (মৌলিক, নির্দিষ্ট, জটিল, আধুনিক)
- 📋 **বন্টন গাইড**: প্রতিটি ওয়ারিশের বিস্তারিত নিয়ম
- 🔍 **সার্চ ফিচার**: সব পেজে সার্চ ও ফিল্টার

### 🎨 UI/UX
- 📱 **রেস্পন্সিভ ডিজাইন**: মোবাইল ও ডেস্কটপে সুন্দর
- 🎨 **আধুনিক UI**: Tailwind CSS v4 দিয়ে তৈরি
- ⚡ **দ্রুত লোডিং**: Vite দিয়ে optimized
- 🌙 **সুন্দর টাইপোগ্রাফি**: বাংলা ফন্ট অপটিমাইজড

## 🛠️ টেকনোলজি স্ট্যাক

- **Frontend**: React 19 + Vite
- **Styling**: Tailwind CSS v4
- **Routing**: React Router DOM v7
- **Charts**: Recharts (Pie Chart)
- **PDF Generation**: jsPDF + jsPDF-AutoTable
- **Icons**: React Icons
- **Language**: JavaScript (ES6+)

## 📦 ইনস্টলেশন

### প্রয়োজনীয় সফটওয়্যার
- Node.js (v18 বা তার বেশি)
- npm বা yarn

### সেটআপ স্টেপ

```bash
# রিপোজিটরি ক্লোন করুন
git clone https://github.com/yourusername/uttoradhikar.git

# প্রজেক্ট ফোল্ডারে যান
cd uttoradhikar

# ডিপেন্ডেন্সি ইনস্টল করুন
npm install

# ডেভেলপমেন্ট সার্ভার চালু করুন
npm run dev
```

ব্রাউজারে `http://localhost:5173` ওপেন করুন।

## 🧮 ক্যালকুলেশন লজিক

এই অ্যাপ্লিকেশনে যে নীতিগুলো প্রয়োগ করা হয়েছে:

### জাবিল ফুরুজ (নির্ধারিত অংশ)
- স্বামী: ১/২ বা ১/৪
- স্ত্রী: ১/৪ বা ১/৮
- মা: ১/৩, ১/৬ বা অবশিষ্টের ১/৩
- বাবা: ১/৬ + আসাবা
- কন্যা: ১/২ বা ২/৩
- সহোদর বোন: ১/২ বা ২/৩
- বৈপিত্রীয় ভাই-বোন: ১/৬ বা ১/৩

### আসাবা (অবশিষ্টাংশ)
নির্ধারিত অংশীদারদের দেওয়ার পর অবশিষ্ট সম্পদ পায়:
1. পুত্র (কন্যাসহ ২:১ অনুপাতে)
2. পুত্রের পুত্র
3. বাবা/দাদা
4. সহোদর/বৈমাত্রীয় ভাই
5. চাচা/চাচাত ভাই

### আউল (Awl)
মোট অংশ ১-এর বেশি হলে সবার অংশ আনুপাতিক হারে কমানো হয়।

### রাদ্দ (Radd)
সম্পদ উদ্বৃত্ত থাকলে ও কোনো আসাবা না থাকলে, স্বামী/স্ত্রী ছাড়া অন্যদের মধ্যে পুনর্বন্টন।

## 🎯 ব্যবহারবিধি

### ক্যালকুলেটর ব্যবহার
1. **সম্পদ ইনপুট**: মৃত ব্যক্তির টাকা, জমি, স্বর্ণ, রুপার পরিমাণ দিন
2. **ওয়ারিশ নির্বাচন**: জীবিত ওয়ারিশদের নির্বাচন করুন
3. **হিসাব করুন**: "বন্টননামা তৈরি করুন" বাটনে ক্লিক করুন
4. **চার্ট দেখুন**: Pie chart-এ ভিজুয়াল বন্টন দেখুন
5. **ডাউনলোড/প্রিন্ট**: ফলাফল PDF বা প্রিন্ট করুন

### শিক্ষামূলক পেজ
- **কুরআন**: সূরা নিসার মূল আয়াত, তাফসীর, ব্যাখ্যা
- **হাদিস**: সহিহ হাদিস সংকলন, সূত্র সহ
- **বিশেষ মাসআলা**: মাফকুদ, হামল, খুনসা - বিস্তারিত
- **FAQ**: ৪টি ক্যাটাগরিতে (মৌলিক, নির্দিষ্ট, জটিল, আধুনিক)
- **বন্টন গাইড**: প্রতিটি ওয়ারিশের নিয়ম
